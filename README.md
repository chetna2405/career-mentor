# Career Mentor

Personalized career guidance and adaptive learning roadmap using machine learning.

## Folders
- `data/`: skills, prerequisites, goal texts, resources (CSV). Run `python validate_data.py` inside `data/` after editing.
- `ml/`: notebooks and saved models
- `backend/`: FastAPI app
- `frontend/`: HTML, CSS, JS
- `docs/`: scope, design docs, ERD, wireframes
